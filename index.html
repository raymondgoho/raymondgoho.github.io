YouTube Likes Sync

A private, personal tool that keeps a running list of videos its owner has liked on YouTube.

What this app is for

YouTube Likes Sync is a single-user automation. Once a day it connects to the YouTube account of its developer (Raymond Goho), reads the videos that account has "liked", and saves that list into a private database on the developer's own computer. The purpose is simple: to keep a permanent, searchable archive of liked videos, because YouTube itself does not offer search over liked videos.

How it works

  • The tool runs on the developer's own computer, not on any public server.
  • It signs in with Google using read-only access (https://www.googleapis.com/auth/youtube.readonly).
  • It cannot post, comment, edit or delete anything — it can only read the list of liked videos.
  • Each run produces a short private summary of newly liked videos.

Read exactly what data this app handles and how it is protected in our Privacy Policy.
